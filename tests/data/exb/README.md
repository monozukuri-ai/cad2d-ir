# EXB test fixtures

Synthetic CAXA EXB compound documents copied byte-for-byte from the `ezexb`
repository's `tests/python/data/` (`document-10.cfb`, `document-18.cfb`,
`document-partial.cfb`) and renamed to `.exb`. They were generated by `ezexb`'s
`make_document_fixture` example and were **not** created by CAXA CAD: they use
the observed build strings `10.0.0.0000` / `18.0.0.18159` only to select the
record layout, and contain no third-party drawing content. They are
redistributed under the preserved [`ezexb` MIT license](LICENSE.ezexb.txt).

```text
repository: https://github.com/monozukuri-ai/ezexb
commit:     5548a18cf867988e412a353e325bf419587daa2d (v0.1.0)
paths:      tests/python/data/document-10.cfb, document-18.cfb, document-partial.cfb
regenerate: cargo run -p ezexb-core --example make_document_fixture -- document-10.cfb 10
            cargo run -p ezexb-core --example make_document_fixture -- document-18.cfb 18
            cargo run -p ezexb-core --example make_document_fixture -- document-partial.cfb 10 --unknown
```

Each document has one space (`Sheet A`, id -7), a layer (`Test layer`, stored
colour `0x123456`, width flag 2 = 0.35 mm), a line type (`Continuous`), a text
style (`Original style`, line spacing 1.5), a block (`Reusable part`, one
circle) and five top-level entities: a line, an arc, a closed polyline, a text
(`Original 日本語`) and an INSERT whose stored matrix deliberately disagrees
with its components (world expansion reports it; the importer uses the
components). The partial document adds one record of an unknown type
(`11111111-1111-1111-1111-111111111111`).

CAXA-authored drawings (dimensions with cached presentation, hatches, NURBS,
title-block attributes) are vendor material and are not included; the opt-in
gate `CAD2D_IR_EXB_FIXTURES` in `tests/test_exb_importer.py` runs them from a
local directory.
